### antislop-human

#### 12 · `outline: none` pada input tanpa replacement focus indicator yang cukup — HIGH (R-32)

[theme.css L1053-L1058](file:///c:/Project/porto2/styles/theme.css#L1053-L1058):
```css
.field__input:focus,
.field__textarea:focus {
  outline: none;
  background: #fff;
  transform: translate(4px, 4px) rotate(0deg);
  box-shadow: 0 0 0 var(--ink);
}
```

Focus menghilangkan outline dan shadow (shadow menjadi `0 0 0`). Satu-satunya feedback visual adalah background berubah ke putih dan posisi bergeser. Ini **tidak** memenuhi 3:1 contrast requirement untuk focus indicator (R-32). Keyboard user tidak bisa melihat field mana yang aktif karena:
- `box-shadow: 0 0 0 var(--ink)` = shadow nol/invisible
- Background change dari `var(--surface)` ke `#fff` terlalu halus (keduanya hampir putih)
- Transform shift mungkin tidak terlihat tanpa konteks visual

**Fix:** Tambahkan visible focus ring, misalnya `box-shadow: 0 0 0 3px var(--ink)` atau gunakan `:focus-visible` global ring yang sudah ada.

#### 14 · Kontras `chip__dot--live` (animasi pulse) — HIGH (R-25)

```css
.chip__dot--live {
  background: var(--moss); /* = #7ac434 */
  box-shadow: 0 0 0 0 rgba(62, 107, 79, 0.5);
  animation: pulseDot 2.4s infinite;
}
```

Dot hijau `#7ac434` di atas surface putih (`#fbfaf6`) = luminance ratio ≈ 2.7:1. Gagal WCAG AA non-text contrast (3:1). Dot ini tanpa teks label; warna saja tidak cukup membedakannya. Di atas `--hue-sun` (`#ffc02e`) ratio bahkan lebih rendah.

**Fix:** Gelapkan dot ke `--accent-deep` atau beri border `var(--ink)` yang sudah ada (`.chip__dot` sudah punya `border: var(--bw-hair) solid var(--ink)` tapi `--live` override-nya mungkin tidak cukup).
